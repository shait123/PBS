# Padmavati Bangle Store

Premium modern e-commerce experience for traditional Indian bangles with customer storefront + secure admin APIs.

## Stack
React + Tailwind + Framer Motion, Node/Express, MongoDB, JWT, bcrypt.

## Features Delivered
- Luxury responsive storefront with sticky nav, hero, themed palette, filtering, sorting, search, wishlist/cart actions, quick view CTA.
- Dark/light mode, glassmorphism cards, animated transitions.
- 3-language UI switcher: English, हिंदी, తెలుగు.
- API for signup/login/admin login, product CRUD (admin-only), orders, analytics-ready models.
- Secure auth with bcrypt password hashing + JWT + role-based route protection.
